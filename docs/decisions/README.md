# Decision records

Short architecture decision records (ADR). One file per decision, numbered `NNNN-title.md`, never edited after acceptance (supersede with a new record instead).

Template:

```markdown
# NNNN. Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD
- Deciders: names

## Context
What problem or constraint led to this decision.

## Options considered
Each option with its main pros and cons.

## Decision
What was chosen, in one paragraph.

## Consequences
What becomes easier, harder, or must be revisited.
```

Records: `0001-stack`, `0002-site-structure`, `0003-analytics`, `0004-self-hosted-fonts`.
